# Запуск в панели

Точка входа: `bot.py` (вызывает `main.py`). Установите зависимости из
`requirements.txt` и задайте `BOT_TOKEN`, `ADMIN_ID`, `API_ID`, `API_HASH`
в защищённых переменных панели. Не добавляйте реальные значения в Git.

База `spam_bot.db` и файлы сессий `user-sessions/` и `qr-sessions/` в
репозиторий не входят. Для сохранения действующих пользователей и кампаний
перенесите их отдельно защищённым способом с остановленного экземпляра бота.
После переноса запускайте только один экземпляр бота. После перезапуска
кампании остаются остановленными и требуют ручного запуска.
