# Telegram Spam Bot

Telegram bot для массовой рассылки сообщений по группам с удобной админ-панелью внутри Telegram.

## ⚠️ Важные предупреждения

- **Userbot**: Этот бот использует ваш личный аккаунт Telegram через Pyrogram для отправки сообщений
- **Ограничения Telegram**: Соблюдайте разумные задержки (60-120 секунд) между отправками чтобы избежать блокировки
- **FloodWait**: Бот автоматически останавливается при получении ограничений от Telegram
- **Ответственность**: Используйте бот ответственно и в соответствии с правилами Telegram

## 🚀 Возможности

- 📝 Настройка поста (текст + фото или текст + видео)
- 📋 Управление списком групп
- ⏱ Настройка интервала повторной отправки отдельно для каждой группы
- ⏱ Одно значение или диапазон в секундах или минутах через выбор в меню
- 👁 Предпросмотр поста перед запуском
- ▶️ Запуск и остановка рассылки
- 🛡 Автоматическая обработка FloodWait ошибок
- 💾 SQLite база данных для хранения всех настроек

## 📋 Требования

- Python 3.10 или выше
- Telegram аккаунт для userbot
- Bot token от [@BotFather](https://t.me/BotFather)
- API credentials от [my.telegram.org](https://my.telegram.org)

## 🔧 Установка

1. **Клонируйте или скачайте проект**

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте конфигурацию:**
   ```bash
   cp .env.example .env
   ```

4. **Отредактируйте `.env` файл:**

   - `BOT_TOKEN`: Получите у [@BotFather](https://t.me/BotFather)
     - Отправьте `/newbot`
     - Следуйте инструкциям
     - Скопируйте полученный токен
   
   - `ADMIN_ID`: Ваш Telegram User ID
     - Получите у [@userinfobot](https://t.me/userinfobot)
     - Отправьте любое сообщение боту
     - Скопируйте ваш ID
   
   - `API_ID` и `API_HASH`: Telegram API credentials
     - Перейдите на [my.telegram.org](https://my.telegram.org)
     - Войдите с вашим номером телефона
     - Перейдите в "API development tools"
     - Создайте приложение
     - Скопируйте `api_id` и `api_hash`
   

## ▶️ Запуск

```bash
python main.py
```

**Сессия отправителя:**
- Каждый пользователь подключает свой Telegram-аккаунт через QR-код в личном чате с ботом.
- QR-код можно открыть на другом экране и отсканировать через «Настройки → Устройства → Подключить устройство».

## 📱 Использование

Главный администратор задаётся переменной `ADMIN_ID` в `.env`. В главном меню ему
доступна кнопка «🔐 Доступ по ID»: через неё можно добавить Telegram ID другого
пользователя или отозвать доступ. Выданные ID сохраняются в SQLite и действуют
после перезапуска. У каждого пользователя собственные кампании, посты, группы
и паузы. Приглашённые пользователи не могут выдавать доступ другим. У каждого
пользователя отдельная сессия отправителя, хранящаяся в папке `user-sessions`.

При отзыве доступа кампании пользователя останавливаются. После перезапуска
все кампании остаются остановленными до ручного запуска. При FloodWait
останавливаются кампании затронутого аккаунта, а новый запуск блокируется
для этого аккаунта на срок ограничения.
По окончании срока кампании автоматически не возобновляются.

1. **Откройте бота в Telegram**
   - Найдите вашего бота по username
   - Отправьте `/start`

2. **Главное меню:**
   - 📝 **Настроить пост** - отправьте текст с фото или видео
   - 📋 **Список групп** - добавьте или удалите группы
   - ⏱ **Интервал для группы** - установите точное время или диапазон в секундах/минутах
   - 👁 **Предпросмотр** - посмотрите как будет выглядеть пост
   - ▶️ **СТАРТ** - начать рассылку
   - ⏹ **СТОП** - остановить рассылку

3. **Добавление групп:**
   - Нажмите "Список групп" → "Добавить группы"
   - Отправьте список через запятую или с новой строки
   - Форматы: `@groupname`, `https://t.me/groupname`, `-100123456789`
   - Или нажмите «Выбрать из Telegram» в личном чате с ботом и выберите группы по одной. Сам выбор не выдаёт аккаунту разрешение отправлять сообщения в группе.

4. **Настройка поста:**
   - Нажмите "Настроить пост"
   - Отправьте сообщение (может быть текст, текст+фото, текст+видео)
   - Пост сохранится в базе данных

5. **Запуск рассылки:**
   - Убедитесь что настроен пост и добавлены группы
   - Нажмите "СТАРТ"
   - Новые группы получают первую попытку последовательно, затем каждая ожидает свой интервал
   - Между попытками в разные группы есть служебная пауза до 10 секунд; при ошибке группа также ждёт свой интервал
   - При FloodWait автоматически остановится

## 🛠 Технологии

- **aiogram 3.x** - современный фреймворк для Telegram Bot API
- **Kurigram 2.2.26** - клиент для Telegram MTProto API
- **aiosqlite** - асинхронная SQLite база данных
- **python-dotenv** - управление переменными окружения
